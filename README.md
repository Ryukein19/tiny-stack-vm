A tiny stack VM for make.fun `tiny-stack-vm-01`: runs each `program.bin` on its `input.bin`, writes the bytes it writes plus its exit code, exactly per the ISA. Practice: **40/40 exact, 1,000,000**. Beats the house baseline (670,000). See NOTES.md.
